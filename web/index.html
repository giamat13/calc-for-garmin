🎨 Custom Calculator Design

Arrange the buttons exactly the way you like, then get a SEED code to paste into the watch app's settings.

1Import Existing Code (Optional)

Already have a SEED? Paste it here to keep editing it.

2Layout Template

Templates set how the buttons are arranged on the keypad - not the colors. Pick a template and keep editing manually from there.

3Main Screen Keypad

Tap one button, then tap a second one - even on a different screen below (Scientific / Advanced / Categories) - to swap them. Any button can move anywhere, including BACK and the digits. ✕ in a button's corner deletes it entirely (it disappears from the watch); drag another button there to bring it back.

4Colors

Full control over how it looks - including the top display's background color.

5Tools Menu (MENU)

Check which tools appear in the menu. Tap one row, then a second, to swap their order.

6Scientific Screen (fx)

Same idea exactly - including swapping a button with one on a completely different screen, and deleting with ✕.

7Advanced Screen (ADV)

8Conversion Categories Screen

9Get Your SEED Code

  1. Copy the SEED code above.
  2. In the Garmin Connect phone app: My Device → Watch Apps → calc-for-garmin → Settings.
  3. Paste the code into the "Theme & menu code" field and save.
  4. The changes sync to the watch automatically within a few seconds.
