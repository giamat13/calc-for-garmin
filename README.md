# Calc for Garmin

מחשבון (widget) לשעוני Garmin, כתוב ב-Monkey C עבור Connect IQ. תומך בביטויים עם סוגריים וחזקות, עריכה עם סמן, משתנים שמורים ופתרון משוואות.

---

## תיאור מפורט

### קונספט
המחשבון בנוי סביב **ביטוי טקסטואלי**: כל לחיצת כפתור מוסיפה תו למחרוזת נוסחה (למשל `"12*(3+4)"`), כך שסוגריים וחזקות מורכבות נבנים בצורה טבעית כמו בכתיבה רגילה. הביטוי כולו מחושב רק בלחיצה על "=", באמצעות פרסר ייעודי.

### תכונות עיקריות
- **מנוע חישוב מבוסס ביטוי** (`CalculatorEngine`) — מנהל את מחרוזת הנוסחה, מצב שגיאה, ותוצאה אחרונה (כפתור ANS).
- **פרסר ביטויים** (`ExprParser`) — מפענח ומעריך את הביטוי, כולל תמיכה במשתנים בעלי שם בתוך הנוסחה (למשל `"A+B*2"`).
- **עריכה עם סמן** — ניתן לזוז שמאלה/ימינה בתוך הביטוי הקיים ולהכניס ערכים (כגון מספר אקראי או תוצאה מומרת) באמצע נוסחה, לא רק בסופה.
- **משתנים בעלי שם** — A/B/C/D דרך מסך VAR ייעודי, וכן X/Y/Z... אוטומטית לאחר פתרון משוואה. המשתנים נשמרים ב-Storage של השעון ונשארים זמינים גם אחרי יציאה וחזרה לאפליקציה.
- **פתרון משוואות** — יכולת לפתור עבור משתנה לא ידוע ולשמור את התוצאה כמשתנה חדש לשימוש חוזר.
- **ניווט בתפריטים** — מסך תפריט ראשי לגישה לפונקציות נוספות (למשל ניקוי משתנים, מעבר בין מסכים).
- **תמיכה רחבה במכשירים** — עשרות דגמי Garmin: Fenix, Forerunner, Edge, Venu, Instinct, Approach, Descent, Epix, Marq ועוד (הרשימה המלאה ב-`manifest.xml`).

### מבנה הקוד
| קובץ | תפקיד |
|---|---|
| `source/CalculatorEngine.mc` | לוגיקת ליבה: ביטוי, סמן, משתנים, משוואות |
| `source/ExprParser.mc` | פרסור והערכה של ביטויים מתמטיים |
| `source/calc-for-garminView.mc` | ציור המקלדת, התפריטים והתוצאה על המסך |
| `source/calc-for-garminDelegate.mc` | טיפול באירועי קלט (לחיצות/מגע) |
| `source/calc-for-garminApp.mc` | נקודת הכניסה לאפליקציה |
| `source/Icons.mc` | ניהול אייקוני SVG בממשק |
| `source/ExprParserTest.mc`, `source/ViewHitTestTest.mc` | בדיקות לפרסר ולזיהוי אזורי לחיצה |
| `tools/gen-icons.mjs` | כלי לייצור/עדכון האייקונים |
| `manifest.xml` | הגדרת האפליקציה, מכשירים נתמכים והרשאות |

### טכנולוגיה
Monkey C, Garmin Connect IQ SDK (widget, `minApiLevel="3.2.0"`), הרשאת Communications.
